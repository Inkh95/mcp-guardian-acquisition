# Security and disclosure

This public repository is a non-code acquisition showroom. It does not contain the MCP Guardian production implementation, proprietary detection logic, deployable configuration, credentials, customer information, or private diligence material.

The private release has automated security tests, locked production and development dependencies, dependency audits reporting no known vulnerabilities at verification time, an explicit threat model, and a CI container smoke test.

Do not report suspected vulnerabilities publicly. Contact the repository owner privately through the GitHub profile and never include real credentials, customer data, or production information.
